# Retocker Manager

Все программы Retocker в одном окне для Windows: поставить, обновить, открыть и удалить.

| Программа | Что это | Откуда берётся |
|---|---|---|
| Retocker Voice | диктовка в любую программу | релизы `retocker-absolute-download` |
| Retocker Snap | скриншоты | релизы `retocker-snap-download` |
| Zapret Manager | менеджер zapret для YouTube и Discord | релизы `zapret-manager2` |
| Retocker Translate | расширение Firefox (в списке помечено «Расширение Firefox») | `rt-update.retocker.workers.dev` |

Скачать: **Retocker-Manager-Setup.exe** на странице [релизов](https://github.com/mishakozlov723-wq/manager/releases/latest).

## Как устроено

- `src-tauri/` — программа на Tauri 2 (Rust), один exe:
  - `apps.rs` — четыре программы: что установлено (реестр Windows, профили Firefox), какая версия вышла (маленький `latest.json` рядом с файлами релиза), установка, обновление, удаление;
  - `setup.rs` — установщик и удаление самого менеджера: exe с «Setup» в имени ставит сам себя, с `--uninstall` — удаляет;
  - `upd.rs` — обновление самого менеджера из релизов этого репозитория;
  - `firefox.rs`, `net.rs`, `sys.rs`, `logx.rs` — Firefox, скачивание, Windows, журнал.
- `ui/` — окно (обычные HTML, CSS и JS, без сборки) в том же стиле, что Retocker Voice: те же цвета, шрифт Manrope, кнопки.
  Открытые в браузере `ui/index.html` и `ui/setup.html` работают на выдуманных данных — так удобно смотреть вид
  (`index.html?fresh`, `?all`, `?offline`, `?self`, `?busy=snap`, `?ask=voice`; `setup.html?mode=uninstall`).

## Как ставятся программы

- **Voice и Snap.** Менеджер скачивает их `…Setup.exe`, сверяет SHA-256 и подпись Ed25519 (те же ключи, которыми программы
  проверяют свои обновления) и запускает с `--silent`. Удаление — `<программа>.exe --uninstall --silent`, с галочкой
  «удалить настройки» ещё и `--wipe`. При обновлении автозапуск и ярлык на рабочем столе остаются как были.
- **Zapret Manager.** У его установщика нет тихого режима: менеджер скачивает файл, сверяет размер и SHA-256 и открывает
  окно установки. Удаление — его `uninstall.exe /S`; служба обхода `ZapretManagerWinws` (только созданная самим
  Zapret Manager) перед этим останавливается и удаляется — на это Windows спрашивает разрешение.
- **Retocker Translate.** Расширение нельзя поставить или удалить в обход Firefox: менеджер открывает в Firefox
  подписанный файл расширения (или страницу дополнений для удаления) и ждёт, пока оно появится в профиле.

Сам менеджер называется `rt-manager.exe`, а не `retocker-…`: установщики Voice и Snap закрывают все запущенные
`retocker*.exe`. По той же причине менеджер после установки одной из этих программ заново запускает вторую, если она работала.

## Сборка и релиз

Собирает GitHub Actions (`.github/workflows/build.yml`) на каждый пуш в `main` и на каждый pull request. Версия — `1.0.<номер сборки>`.

После сборки `scripts/check.ps1` на той же машине ставит менеджер через его окно, ставит и удаляет настоящие Voice и Snap,
обновляет менеджер из тестового файла и удаляет его. Снимки экрана и `check.txt` попадают в ветку `ci-shots`.

Релиз выходит, когда в сообщении коммита в `main` есть `[release]`: в релиз кладутся `Retocker-Manager-Setup.exe` и `latest.json`,
текст берётся из `RELEASE.md`. Установленные менеджеры видят новую версию сами и предлагают обновиться.

Обновление менеджера проверяется по размеру и SHA-256 из `latest.json` и скачивается только из релизов этого репозитория.
